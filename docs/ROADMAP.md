## Киллер-фичи

### [~] «До последней капли» (battery sag guard)

**Цель:** не допускать просадки напряжения батареи ниже установленного порога при нажатии газа. Штатный контроллер жёстко отрубает питание по undervoltage cutoff — наша прошивка должна упредить этот момент: плавно ограничивать выход газа (DAC 1.1–4.1В), чтобы просадка упиралась в порог и не пробивала его. Едешь «до последней капли», но без рывков и отключений.

**Источник данных о напряжении — 1-пиновая обратная связь от контроллера:**
- У штатного контроллера (дешёвый класс) есть 1-проводная линия данных — вероятно, общий стандарт однопроводного протокола (семейства KT/Lishui/SIF): последовательные фреймы, где есть вольтаж батареи и, возможно, ток/скорость/ошибки.
- **Этап 0 — разведка [~]:** подключить линию к свободному GPIO (кандидаты 35/36/39, input-only) через согласование уровней, записать сырой поток уже существующим механизмом **bus capture** (`src/system/debug_capture.{h,cpp}`, пин выбирается на /debug: GPIO35/36/39) и расшифровать протокол (частота, фрейм, поле вольтажа).
- Делитель напряжения на ADC (GPIO35) — запасной вариант, если линия не поддастся расшифровке.

**Архитектура (черновик):**
- Новый модуль `src/core/battery_guard.{h,cpp}`: фильтрация (медиана + EMA), медленный EMA «напряжения покоя» при газе ≈ 0, функция `batteryGuardClampV(targetOutV)` — один хук в `updateThrottle()` после расчёта `combinedV`, до `dacWrite()`.
- Настройки в NVS (по паттерну `cruiseSettingsSave`): вкл/выкл, V_floor, гистерезис, выученный лимит газа.
- Веб: страница «Батарея», поле в `/api/status`, журнал через events_engine.

**Калибровка:**
- Ручной режим: ввод V_floor (если известен порог отсечки контроллера); либо стенд: полный газ на подставке → кривая V_rest → V_sag_full → расчёт запаса.
- Обучающий режим: прошивка логирует напряжение и % газа в момент пробоя порога, сама вычисляет рабочий порог с запасом; cap мгновенно падает при пробое и медленно восстанавливается (адаптация к заряду/температуре).
- **Гистерезис обязателен:** ~0.15–0.3 В + мин. время удержания ограничения 0.5–1 с, иначе пила «ограничил → отпустило → снова просадка».

**Fail-safe:** обрыв/мусор на линии → функция выключается, газ работает как раньше (отсутствие данных не должно оставить без газа в дороге). В сервис-режиме и при торможении guard не вмешивается.
